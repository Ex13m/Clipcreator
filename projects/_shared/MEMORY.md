## Уроки
- Презентации спонсоров ≠ наш стиль: оператор хочет современный рекламный ролик продуктов, у каждого спонсора свой визуальный мир; от TA — только логотип. Каждый блок = отдельный Reels.
- Вырезка фона офлайн: npm `@imgly/background-removal-node@1.4.5` (веса ISNet внутри npm-пакета, сеть не нужна) — отлично для блёсен/воблеров/рендеров. Не годится для пастельных бутылок на белом (полупрозрачные) и тонких крючков (теряет проволоку) → классика: порог+fill-holes / luma-key. Скрипты: `mcr-2026-sponzori/scripts/assets_prep/`.
- Troutshop: водяной знак TROUTSHOP.EU в части фото лежит поверх блесны — такие кадры отбраковывать, в PNG брать собственную альфу магазина. Мелкие плоские логотипы (408 px) — векторизация vtracer по цветовым слоям (unmix) → рендер 2000 px.
- Klonówiec v14: удлинение подиума и лишние фото сдвинули сцены с бита → откат. Правки только без сдвига таймингов или с пересчётом сетки.
- Карточки в 16:9 уезжали за экран: `box-sizing:border-box; width:auto; right:0` только для 16:9.
- «Рассинхрон звука» оказался низким битрейтом превью — превью с `-g 30`.
- Контейнер: 4 ядра → воркфлоу выполняет ~2 агента одновременно; крупные задачи планировать с учётом этого.
- При рестарте контейнера фоновый рендер умирает — перезапускать.
- HyperFrames суб-композиции (MČR спонсоры): в `compositions/*.html` пути к ассетам от корня проекта (`assets/…`), не `../assets/` (lint `invalid_parent_traversal_in_asset_path`). CSS из root действует и на суб-композиции; то, что живёт поверх блоков (плашка TA, её перелёты), — только в ROOT timeline: суб-композиция не может анимировать элементы хоста.
- Маскированные титры (overflow:hidden) обрезали диакритику (Í, Č) и 2-ю строку во flex-колонке: `padding-top:.1em; margin-top:-.1em` + `flex-shrink:0` у детей.
- MČR ревью: подготовленные ассеты (`assets_prep/` — вырезки без водяных знаков, b-roll 1080×1920) надо реально подключить в `content.json`, иначе в кадр идут сырые фото магазинов (водяной знак, «glow»-панель, тиски, BACK/FRONT). Мелкие packshot'ы — `object-fit:scale-down` (не апскейлить).
- Швы 6 с лупов: всё, что дрейфует через весь блок (zoom фона, marquee), в лупе — туда-обратно (sine), вращение — кратно симметрии (шестерня GH = 60°), первый кадр лупа = чистый «постер» (без сдвига титра). В лупе без VO. Чешская типографика: NBSP после v/k/s/z/o/u/a/i и в «1 300», «6 hodin».
- Премиум-вырезки (MČR, Velká ryba): Higgsfield `upscale_image` 2k (bytedance) стоит 2 кредита. Он выдумывает мелкие детали (torx-винты превратились в «решётки»), поэтому мелочи надо латать из Lanczos-оригинала. Тиснёный текст передаёт верно. Фон с белых packshot'ов лучше снимать локально, без HF `remove_background`: ISNet-тримап + unmixing по белому + «всё замкнутое непрозрачно, кроме бумажно-белых дыр» (`mcr-2026-sponzori/scripts/assets_prep/velkaryba_ad/cut.py`). Получается без ореолов, с жалами крючков и открытыми отверстиями. Апскейл тянет вокруг объекта серую «дымку» шириной ~25 px, поэтому порог по яркости не годится, нужен тример.
- Шрифты MČR: реестр `scripts/lib/fonts.mjs` + файлы `mcr-2026-sponzori/fonts/` (woff2 и `_ttf/` для замера fontkit); `proto/assets/fonts.css` — старый путь.
- Jigovky (MČR ads): Higgsfield upscale 4k стоит столько же, сколько 2k (2 кр.) — брать 4k. Апскейлер добавляет фактуру бумаги и резкие пылинки → локальный ключ по белому (halo guard + ретушь пылинок). Для блёсен/джигов на чистом белом (255) локальный white-key лучше remove_background: держит проволоку и очко; ловушки — заливка дырки очка (fill_holes), светлый кант на тёмной проволоке (нужна относительная альфа у края), хром-блики (защищать тело вписанной окружностью). Скрипт: `mcr-2026-sponzori/scripts/assets_prep/prep_jigovky_ads.py`.
- Bosset (MČR ads): бутылки на чистом белом (255) лучше всего режутся **без ISNet**: маска = темнота > 10, заливка по строкам между крайними точками (пастельные блики не прогрызают дыры), кромка = рампа темноты относительно тона края + цвет кромки изнутри (`mcr-2026-sponzori/scripts/assets_prep/bosset_ad/build.py::dark_cut`). ISNet «растекается» по чистому белому у края кадра (белые язычки под донышком) → обнулять ISNet там, где фото бумажно-белое (`clean_isnet`). После апскейла мягкой приманки на кромке белая «пыль» → сглаженный контур, сдвинутый на 2 px внутрь, цвет кромки из 6 px внутри (`smooth_cut`).
- Мост: мелкие файлы (< ~60 KB) Drive `download_file_content` возвращает прямо в контекст (не в файл). Чтобы base64 ушёл в tool-results файл, грузить через `https://images.weserv.nl/?url=<cdn…>&output=png&l=0` (PNG без потерь, крупнее). Shoptet-магазины: `?order=bestseller|price|-price` и фильтр «Značky» с количествами на `/znacky/` дают картину ассортимента за 1–2 запроса.
- Шрифт Bosset: **Saira** (variable wght 100–900 × wdth 50–125, `fonts/saira-*-wdth-normal.woff2`): Saira Expanded Black ≈ широкие квадратные буквы логотипа BOSSET. Orbitron без latin-ext (нет чешской диакритики).
- MČR движок v5: каждый блок = модуль `(ctx) => {html, css, timeline}`; общие файлы (`build.mjs`, `lib/*`) агенты блоков не трогают. Переходы стыкуются через цвет (`tOut` закрывает кадр `next.theme.bg`, `tIn` открывает со своего `theme.bg`). «Жидкий» blob-переход = круги clip-path + SVG goo-фильтр (blur + альфа-порог) на контейнере больше кадра (иначе края кадра прозрачнеют). Дрон: пока нет `drone/final/`, venue берёт свежий черновик `drone/mesh/out/v<N>/`.

- Troutshop (MČR ads): у ISNet-вырезок с белого фона остаются белые рваные кольца в очках блёсен и светлый кант 1–5 px. Финальный пасс `mcr-2026-sponzori/scripts/assets_prep/ts_polish.py` делает три вещи. Круглое очко, целиком окружённое телом, перевписывает гладким эллипсом; там, где через очко проходит кольцо или крючок, эллипс не ставит (иначе прорежет проволоку). На сочных телах заменяет кант цветом интерьера. С крючков снимает белёсую «дымку» по яркости. Прозрачный крэнк обрабатывается отдельным режимом `clear_lure`: тело остаётся полупрозрачным, крючки собираются заново по яркости. QA: crop всех очков до/после в один лист.
- Ассортимент WooCommerce/WoodMart-магазинов через мост: число в категории берётся из «Showing 1–36 of N results», по брендам — из ссылок `filter_brand` (счётчики), бестселлеры — из `?orderby=popularity`, шрифты и цвета — из `xts-theme_settings_default-*.css` (`--wd-title-font`, `--wd-primary-color`).
- Activefishing (MČR ads): у Shoptet `user/shop/orig/` у блёсен/воблеров всего 800×600 (а «big» 1024×768 — увеличение самого Shoptet) → для героев HF upscale 4k (2 кр.). Неудачный job HF возвращает кредиты сам — просто повторить. Локальная вырезка: cutout3 + `open_white` (переоткрыть очки/отверстия, залитые правилом «замкнутое = непрозрачное») + `decontaminate` (цвет края из ближайшей внутренней точки + choke 8 %) — убирает ореол апскейлера на любом фоне; катушки лески (VARIVAS) — белая этикетка съедается white-key → заливать замкнутые карманы, кроме нижнего «прозрачного» фланца (`scripts/assets_prep/activefishing_ad/cut_af.py`). Мелкие файлы (< ~30 KB) Drive `download_file_content` отдаёт inline, а не в tool-results — их на диск не достать, брать крупнее. Шрифт логотипа Activefishing ≈ Saira Extra Condensed 900 (fonts/, OFL).
- HeyGen TTS (eleven_v3) режет последнее слово по своему `<end>`. Приём « …» в конце текста помогает не всегда: в MČR подтверждённо сработал в 3 из 5 скачанных дублей (bosset, troutshop, finale), venue и moonky всё равно обрезаны; velkaryba не скачан. Проверка: последние 30 мс raw ниже −50 dBFS. Обработка: хвост с естественным затуханием и fade 120 мс; для обрезанной гласной — синтетическое затухание (продолжение последнего периода по YIN, −40 дБ за 80 мс), скрипт `scratchpad/vo2/process_v2.py`. Загрузку через мост (Zapier → Drive) классификатор разрешений может отклонить для отдельного URL (у velkaryba так и вышло). Прямой curl на resource2.heygen.ai даёт 403.
- Громкость VO: linear loudnorm с `TP=-1` даёт по фильтру BS.1770 4× около −0.98 dBTP, а ffmpeg ebur128 округляет это до «−1.0», и превышение не видно. Проверять true peak с точностью до сотых (`loudnorm print_format=json` → `input_tp`) и после loudnorm добавлять `volume=-0.05dB` (в `process_v2.py` уже добавлено). Итог ≈ −1.03 dBTP, громкость −16.05 LUFS.
- MČR финал (`blocks/finale.mjs`): монтаж «1 партнёр = 1 доля» (жёсткие склейки цветовых миров бренда + продукт + имя бренда его шрифтом тон-в-тон), цвет заголовка переключается на каждой склейке (тёмный на светлых мирах) → читаемо на любом фоне. Взрыв продуктов из-за логотипа TA → «созвездие» с глубиной резкости (мелкие резкие у логотипа, крупные размытые по краям). Лого-стена «равный вес» = одинаковая площадь: `w = min(maxW, sqrt(A·ar), maxH·ar)`. Lint `composition_heavy_overlay_count_high`: поле и ореол объединять в один слой с двумя radial-gradient.
- MČR интро (`blocks/intro.mjs` + `lib/fx_intro.mjs`): lint `composition_heavy_overlay_count_high` (≥ ~40 элементов с radial-gradient / filter:blur / clip-path, даже скрытых) → риск чёрных кадров в захвате. Лечится: один фон + один glow на всю серию strobe-карточек (цвет меняется `tl.set`, glow = `radial-gradient(currentColor…)`), blur только на время движения (`tl.set` filter перед твином и `none` после), продукты без тени, где она не нужна. Обратный отсчёт в `mix-blend-mode:difference` поверх брендовых фонов читается на любом цвете. Тексты, входящие на склейке, стартуют на ~0,08 с раньше, иначе кадр сильной доли пустой.
- Gausse Holler (MČR ads): у Shopify-магазинов весь каталог отдаёт один запрос через мост: `/products.json?limit=250` + `/collections.json` (типы, цены, варианты, URL рендеров 2048 px).
