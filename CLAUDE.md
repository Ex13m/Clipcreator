# Clipcreator — правила репозитория

- Каждый ролик = отдельный проект в `projects/<slug>/` (свои ассеты, скрипты, рендеры, README/BRIEF).
- **Общая память всех проектов: `projects/_shared/MEMORY.md` — прочитать перед любой работой над роликом и дополнять после** (уроки, индекс проектов, новые люди/партнёры/инструменты).
- Общие брендовые ассеты TA CZ / GH: `projects/_shared/brand/`. Сетевой мост: `projects/_shared/BRIDGE.md`.
- Ответы оператору — по-русски, кратко; тексты для публикаций/VO — по-чешски.
